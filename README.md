# 🕸️ Web Scraping con Python

Este taller tiene como objetivo enseñar cómo obtener datos de forma ágil y sencilla desde páginas web, con el fin de facilitar la recopilación de información necesaria para desarrollar proyectos de análisis o recomendación.

## 📚 Librerías utilizadas

Este taller se enfocará en extraer datos de la página [Ciencuadras.com](https://www.ciencuadras.com/) para analizarlos y generar un asistente virtual que recomiende propiedades. Además, se usará [CodeShare.io](https://codeshare.io/) para compartir código en tiempo real.

## ⚙️ Instalación de dependencias

Ejecuta los siguientes comandos en Git Bash o tu terminal preferida:

```bash
pip install selenium
pip install webdriver-manager
pip install pandas

```
